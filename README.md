# 我的课表 PWA

## 功能

这是一个适合手机查看的 2026 年秋季学期个人课表，支持本周、今天和总课表视图，并可离线使用及添加到手机主屏幕。

## 使用方法

PWA 必须通过 `localhost` 或 HTTPS 访问，不能直接双击 HTML 文件完成安装。

在本目录运行：

```powershell
python -m http.server 8000
```

然后在电脑浏览器打开 `http://localhost:8000`。如需在手机使用，请将本项目部署到任意 HTTPS 静态网站服务，再通过手机浏览器访问并选择“添加到主屏幕”。

## 参数修改

学期起始日期、总周数和课程数据集中放在 `app.js` 文件开头。修改资源后，应同步递增 `service-worker.js` 中的缓存版本号，确保已安装设备获取新版文件。
